FoxWorx MotionLab release candidate

Local image and video creation for Windows. Your prompts, references, and generated files stay on your computer.

Get started

  1. Extract the entire package to a local folder such as C:\Image Studio. Keep the folders together. Avoid Program Files, network drives, and cloud-synced folders.
  2. Run Setup.cmd. It detects your GPU and RAM, then lets you choose the models you want. No model is selected automatically. Keep core-only mode for planning/imported media without GPU downloads. Read each model's license before using it.
  3. Click Install selected. The engine is about 2 GB, plus the models below. Downloads are checked against pinned SHA-256 checksums. If interrupted, run Setup again to resume.
  4. Open Start Image Studio.cmd. Choose a model, write a description, and click Generate. Start with 1 megapixel, one reference, or a 3-second video.

Hardware estimates, not certified minimums: Prior generation tests used a desktop RTX 4090 24 GB, sometimes with constrained headroom. They do not certify a physical 16 GB laptop. For NVIDIA generation, use AC power, close games and other GPU applications, and keep Windows' page file system-managed. A current NVIDIA driver is required; this package checks for 580.88 or newer. The CUDA toolkit is included with the engine, so it does not need a separate installation.

Using the app

  • Still images: choose a model and prompt. Qwen supports editing; put the main image first in References, or use Edit this image.
  • Videos: choose From text or From image. Animate uses the current image as the first frame. Play, pause, seek, export, or import clips.
  • References: add up to ten images, assign roles and notes, and reorder them. Save set makes copies; keep the JSON and its matching .images folder together.
  • Prompt Builder: choose Image or Video. Video prompts include movement, camera direction, pacing, and sound, with actions for text-to-video or image-to-video. Choose duration and a first frame in Videos. Written image and video prompts are saved separately. Both image and video drafts support optional Qwen3.5 refinement using the selected generation model profile, plus Undo. Building or transferring a prompt does not start generation.
  • Models & LoRAs: use Download models to add models later. Put compatible LoRAs in models/loras, then Refresh library. Set strength and enable each LoRA separately.
  • Saved work: generations are in output, with prompt/settings JSON beside them. Delete image and Delete video ask for confirmation, then remove the actual media and metadata from that folder into the Windows Recycle Bin. Imported videos are copies; the original import source stays intact.
  • Cancel/reopen: cancellation targets this app's job. Closing during a generation can leave it running; reopening reconnects. To release GPU memory after use, close the app and run Stop Image Studio.cmd when the queue is idle.

If setup needs attention

  • Old or missing driver: get the appropriate notebook driver from NVIDIA, restart Windows, and rerun Setup.
  • Missing VCRUNTIME or c10.dll: install the Microsoft Visual C++ x64 runtime, then retry. The app's .NET runtime and engine's Python runtime are already included or downloaded.
  • Download interrupted: rerun Setup with the same choices. Partial files are resumed; valid files are reused.
  • Out of memory: use 1 megapixel, fewer references, shorter videos, and close other GPU applications. Keep the Windows page file system-managed. Model and scene complexity affect memory use.
  • Preview codec unavailable: use Open to play the video in your external player.
  • More detail: setup logs are in logs/setup.log and logs/setup-errors.log; app errors are in logs/desktop-errors.log.

This portable package does not contain anyone's prompts, references, generated media, or account credentials. Model downloads require internet access; generation is local. It is an unsigned personal distribution and Windows may show a publisher warning. Verify the supplied SHA-256 checksum and source before opening.

Runtime basis: official ComfyUI Portable, pinned to version 0.42.1. See licenses for included notices. Tests and limits are recorded in TEST RESULTS.txt.
